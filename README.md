# Catálogo TrueLove

Catálogo web hecho con React + Vite.

## Uso

```bash
npm install
npm run dev
```

## Estructura

```
src/
  components/   Componentes reutilizables
  pages/        Páginas/vistas
  data/         Datos de productos
  assets/       Imágenes y recursos
  styles/       Estilos globales
```
